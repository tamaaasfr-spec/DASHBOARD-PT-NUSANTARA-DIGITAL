Data Source Configuration

Paste the link of your Google Sheets file. The dashboard reads the six sheets directly from it and refreshes automatically — no need to edit or re-upload this page when the data changes.

The URL is saved in this browser only. “Copy shareable link” gives a link that opens the dashboard already connected to this sheet.

Spreadsheet access

No API key or password is used. The sheet only needs to be readable by link:

  1. Open the sheet → Share → General access.
  2. Choose Anyone with the link and role Viewer.
  3. Keep the six sheet names and the column headers exactly as in the template.

Only people with edit access to the sheet can change the data; the dashboard is read-only.
