Sumber Data Google Sheets

Hubungkan dashboard dengan spreadsheet Anda dalam 3 langkah

1
Impor dataset

Di Google Sheets: File → Import → Upload → pilih Sales_Financial_Dataset.xlsx → Insert new sheet(s). Jangan ubah nama sheet dan kolom.

2
Atur akses

Klik Share → General access → Anyone with the link → peran Viewer.

3
Tempel URL

Salin URL dari address bar browser, lalu tempel pada kolom di bawah.

Data dibaca ulang otomatis setiap 60 detik. Tidak ada kunci API atau password yang dipakai.
